# UI Implementation Rules

Version: 1.0

---

# Purpose

Ensure every screen feels like the same premium application.

Never create custom spacing or typography outside the design system.

---

# Layout

Screen Padding

20px

Section Gap

32px

Card Gap

16px

Button Height

56px

Input Height

56px

Bottom Safe Area

24px

---

# Typography

Display

32

Heading

28

Title

22

Body

16

Caption

14

Small

12

Never invent new font sizes.

---

# Colors

Use only theme colors.

Never hardcode HEX values.

---

# Components

Always reuse

Button

Card

Input

Progress Ring

Metric Card

Timeline

Bottom Navigation

Never redesign components inside screens.

---

# Animations

Duration

200–300ms

Use

Fade

Slide

Scale

Avoid

Bounce

Shake

Flash

---

# Loading

Always use Skeleton UI.

Never show blank screens.

---

# Empty States

Every screen must support

Loading

Error

Empty

Success

---

# Accessibility

Minimum touch target

44x44

Support Dynamic Fonts

VoiceOver labels required

---

# Responsive

Support

Small Phones

Large Phones

Tablets (future)

Never use fixed heights unless required.

---

# Images

Lazy load where possible.

Compress before upload.

Cache thumbnails.

---

# Dark Mode

Every screen must support

Light

Dark

Never use fixed colors.

# Final Principle

Every new screen should look like it belongs to SkinCoach without introducing new visual patterns.
