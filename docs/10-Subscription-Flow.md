# Overview

SkinCoach follows a freemium subscription model.

The goal is to let users experience the value of AI-powered skin tracking before upgrading to Pro.

The subscription model should never feel aggressive.

Instead, premium features should unlock naturally as users become engaged.

# UX Principles

Never pressure users.

Never show excessive paywalls.

Let users experience value first.

Upgrade requests should feel helpful, not intrusive.

Focus on long-term trust rather than short-term conversions.

# Final Principle

SkinCoach earns revenue by helping users build healthier skin habits.

The subscription should feel like an investment in their long-term skin health—not a barrier to using the app.
